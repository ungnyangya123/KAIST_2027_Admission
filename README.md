# KAIST 면접 대비 (물리 · 수학 · 영어 · 적합성)

2020~2026학년도 KAIST 면접 기출을 바탕으로 만든 학습 앱입니다. (제작: 유성민)
맨 위의 **물리 · 수학 · 영어 · 적합성** 버튼으로 과목을 바꿉니다.

- **물리**: 개념(단원순/빈도순), 공식 카드·증명·쓰기 테스트, 확인 문제, 기출 22문항, 파이널 10회 × 2문항
- **수학**: 개념 34개, 공식 카드·유도·쓰기 테스트, 확인 문제, 기출 21문항(쓰인 공식 힌트, 다른 풀이), 파이널 10회 × 2문항
- **영어**: 기출 어휘·질문 표현, 유형·문법 정리, 어휘 퀴즈, 기출 7세트, 예상 문제 12세트(참고 자동 점수 + 영어 스크립트)
- **적합성**: 답변 틀, 기출 7세트(2022~2026 공통문제), 사회 이슈 예상 문제 12세트
- **실전 60분**: 적합성 → 10분 뒤 물리 → 25분 뒤 수학·영어가 알림으로 도착. 기출 실전 5회(2022~2026) / 예상 문제 실전 10회. 과목별 구상지, 끝낸 뒤 해설
- 타이머는 시작 시각을 저장해 계산하므로 화면이 꺼지거나 새로고침해도 이어집니다. (파이널 10·25분, 영어 5분, 적합성 10분 알림)

## 사용법
`index.html` 파일 하나로 동작합니다. 내려받은 뒤 더블클릭해 브라우저(Chrome·Edge·Safari)로 열면 됩니다.
인터넷이 없어도 동작하며, 연결되어 있으면 웹 글꼴이 적용됩니다.
학습 기록은 사용하는 브라우저 안에만 저장됩니다(과목별로 따로 저장).

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들고 `index.html`, `README.md`를 올립니다.
2. Settings → Pages → Branch를 `main` / `(root)`로 저장하면 몇 분 뒤 주소가 생깁니다.

- 수학·과학·영어 기출: KAIST 선행학습 영향평가 공개 문항. 적합성 공통문제: KAIST 학사과정 공통문제 원문.
- 풀이·해설·예시 답안·예상 문제는 제작자가 새로 쓴 연습용이며 공식 답안이 아닙니다.
