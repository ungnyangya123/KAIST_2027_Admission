# KAIST 면접 물리 연습

2020~2026학년도 KAIST 면접 물리 기출을 바탕으로 만든 학습 앱입니다. (제작: 유성민)

- 개념 (단원순 / 기출 빈도순), 공식 카드·증명·공식 쓰기 테스트
- 확인 문제, 기출 22문항 (풀이 공간, 예시 답안, 면접 답변 예시)
- 파이널 10회 × 2문항 (시간 측정, 10·25분 알림, 채점 기준으로 자기 채점)
- 수식은 키보드(자동 채점) 또는 손글씨(정답 보고 스스로 채점)로 입력

## 사용법
`index.html` 파일 하나로 동작합니다. 내려받은 뒤 더블클릭해 브라우저(Chrome·Edge 권장)로 열면 됩니다.
인터넷이 없어도 동작하며, 연결되어 있으면 웹 글꼴(검은고딕·나눔명조)이 적용됩니다.

학습 기록은 사용하는 브라우저 안에만 저장됩니다. 다른 기기·브라우저와는 공유되지 않습니다.
